Install

安装与首次使用

第一次打开要先选数据目录、设主密码，留两三分钟就够。

Windows

  1. 下载安装版 exe 或绿色版 zip。绿色版解压到空间充足的非系统盘，比如 D:\知人。
  2. 运行安装包，或双击解压后的 zhiren.exe。遇到 SmartScreen 选「更多信息 → 仍要运行」。
  3. 选择数据目录：建议放非系统盘；这个目录里会生成加密数据库和附件目录。
  4. 设置主密码（至少 8 位），把一次性显示的 24 位恢复密钥抄下来。
  5. 开始记录：添加第一个人，从「记行为」或「写日记」开始。

Android

  1. 下载 APK 并传到手机（数据线、网盘、扫码下载都可以）。
  2. 允许安装：在系统提示里允许「安装未知应用 / 来自此来源的应用」。
  3. 打开应用：选数据目录（默认的应用私有目录就挺好），设置主密码并保存恢复密钥。
  4. 授权：通知、麦克风、相机权限，在对应功能第一次使用时按提示给就行。
  5. 同步：和电脑连同一个 Wi-Fi，在「同步中心」扫码，或输入 IP:端口 + 配对码。
Windows 用户注意：第一次用局域网同步时系统会弹防火墙提示，记得勾「专用网络」并允许， 不然只能手动输入 IP。路由器如果开了 AP 隔离，两台设备可能互相发现不了。

FAQ

常见问题

GitHub 下载很慢，甚至打不开怎么办？
可以先试试镜像：在 GitHub Releases 文件地址前加上 https://gh-proxy.com/ 或 https://ghfast.top/ 再打开；也可以在下载工具里给 GitHub 配加速。 站点维护者还可以用 Cloudflare Worker 反代 Release 下载，让下载链接变成自己的域名， 具体做法见部署教程 docs/WEBSITE_DEPLOY.md。
Windows 提示「Windows 已保护你的电脑」怎么办？
这是 SmartScreen 对没签名的新应用常见的提醒。确认文件来自本站或官方 GitHub Releases 后， 点「更多信息 → 仍要运行」就行。介意的话也可以在本地给 exe 签名后再打包。
Android 安装时提示「未知来源应用」？
在系统设置里允许当前浏览器 / 文件管理器「安装未知应用」，有的系统叫「允许此来源」。 装完再把权限关掉也可以。APK 是 release 构建，没有申请多余权限。
忘记主密码会怎样？
初始化时生成的 24 位恢复密钥可以重置主密码。如果恢复密钥也丢了，因为数据是本地端到端加密的， 开发者也没法帮你恢复。第一次用时务必把恢复密钥抄在纸上或密码管理器里。
怎么确认下载的文件没坏？
Windows 命令行执行 certutil -hashfile 文件名 SHA256，或 PowerShell Get-FileHash -Algorithm SHA256 文件名；macOS / Linux 用 sha256sum 文件名。把结果和上方对应卡片的 SHA256 对一下即可。
同步连不上手机 / 电脑怎么办？
挨个检查：两台设备是不是同一个 Wi-Fi；Windows 有没有在防火墙提示里允许「专用网络」； 路由器是不是开了 AP 隔离（开了就改用手动 IP:端口 连接）；双方是不是都停在同步页面。 还不行的话，用「设置 → 数据」导出加密备份手动迁移也稳妥。
数据保存在哪里？换设备怎么迁移？
数据保存在你第一次启动时选的数据目录里：加密数据库、附件、隐藏空间、备份都在那儿。 迁移有两种方式：同一 Wi-Fi 下「同步中心」直连同步；或导出 .zhiren 加密备份， 在新设备导入（需要备份口令）。注意：同步和备份都不会传主密码。
